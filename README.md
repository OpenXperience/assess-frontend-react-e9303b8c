# Build a Login Form Component

Build a React component `LoginForm` that renders an email field, a password field, and a submit button.

## Done when

- A labeled email input.
- A labeled password input (type=password).
- A submit button.
- The component is exported as default from `src/LoginForm.jsx`.
- It renders without crashing.

## How to submit

1. `git checkout -b task`
2. Build it, committing as you go — small commits, clear messages.
3. `git push -u origin task`
4. Open a pull request, then paste its URL back into OpenExp.

Your checks run automatically when you open the pull request.
